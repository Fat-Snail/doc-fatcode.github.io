# doc-fatcode

项目研发流程思维导图

## 访问地址

https://fat-snail.github.io/doc-fatcode/

## 项目说明

这是一个使用 Markmap 创建的项目研发流程思维导图，包含了从立项到交付的完整流程：

- **立项**：需求分析、原型图制作、需求落地、项目建立
- **实施**：人员安排、开发流程、构建部署、测试质控、版本发布
- **交付**：培训、运维、售后、客服
- **后续**：敏捷开发、新功能立项

## 技术栈

- Markmap：用于创建思维导图
- D3.js：数据可视化
- Markmap Toolbar：思维导图工具栏
